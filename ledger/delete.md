# 데이터 삭제 요청 안내 (간편 가계부)

- **앱 이름:** 간편 가계부 (simple_ledger)
- **개발자:** firepig
- **문의:** firepig.jjanggu@gmail.com

본 페이지는 「간편 가계부」 앱 이용자가 자신의 데이터를 삭제하는 방법을 안내합니다.

## 1. 앱 안에서 직접 삭제 (권장 — 즉시 처리)

본 앱은 별도 요청 없이 이용자가 직접 모든 데이터를 삭제할 수 있는 기능을 제공합니다.

1. 앱 실행 → **설정** 탭 → **전체 데이터 삭제**
2. "클라우드 백업도 함께 삭제"가 체크되어 있는지 확인 (기본 체크)
3. 확인 절차를 거치면 기기 데이터와 서버 백업이 함께 삭제됩니다.

앱을 삭제(제거)하면 기기 안의 데이터는 자동으로 제거됩니다. 다만 이전에 실행한 클라우드 백업이 서버에 남아 있을 수 있으므로, 앱 제거 전에 위 기능을 사용하는 것을 권장합니다.

## 2. 이메일로 삭제 요청

앱을 이미 삭제했거나 앱 내 삭제가 어려운 경우, 아래 이메일로 요청해 주시면 처리해 드립니다.

- **이메일:** firepig.jjanggu@gmail.com
- **제목 예시:** `[데이터 삭제 요청] 간편 가계부`
- 요청 접수 후 **14일 이내** 처리하고 결과를 회신합니다.

## 3. 삭제되는 데이터 항목

| 데이터 | 처리 |
|---|---|
| 거래 내역·예산·정기거래 설정 (기기 저장) | 앱 내 전체 삭제 또는 앱 제거 시 **즉시 삭제** |
| 클라우드 백업 (거래 내역·백업 시각·건수) | 앱 내 전체 삭제("클라우드 백업도 함께 삭제" 체크) 시 **즉시 삭제**, 또는 이메일 요청 시 14일 이내 삭제 |
| 익명 인증 ID(UID) | 삭제 요청 처리 시 **삭제** |

## 4. 유의 사항

본 앱은 실명, 이메일, 전화번호 등 개인 식별 정보를 수집하지 않습니다. 이메일로 삭제를 요청하시는 경우 대략적인 백업 실행 시점을 알려주시면 대상 확인에 도움이 됩니다.
