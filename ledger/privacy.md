**시행일: 2026-08-03**

## 1. 수집하는 정보
- 익명 ID (Firebase Authentication 자동 생성)
- 앱 이용 기록 (백업 실행 시각·백업 건수)
- 기기 정보·충돌 로그·사용 통계 (사용 시), IP 주소 (Firebase 자동)
- **가계부 거래 내역**: 이용자가 앱 내 "클라우드 백업" 메뉴에서 백업을 직접 실행할 때만, 저장된 거래 내역(금액·카테고리·메모·날짜)이 Firebase 서버로 전송·저장됩니다. 데이터는 익명 인증 ID(uid)로 격리되어 본인 기기에서만 조회·복원할 수 있으며, 백업을 실행하지 않으면 거래 내역은 기기에만 저장되고 서버로 전송되지 않습니다.

**수집하지 않는 정보**: 실명, 이메일, 전화번호 등 직접 식별 정보. 광고 식별자(본 앱은 광고를 게재하지 않습니다).

## 2. 데이터 저장/처리

- 통신은 HTTPS 암호화, Firebase 보안 규칙으로 접근이 제한됩니다.

- 서버 백업 데이터: **설정 > 전체 데이터 삭제**에서 "클라우드 백업도 함께 삭제"를 체크하면 서버 백업까지 삭제됩니다.
