본 앱에서 수집한 데이터를 삭제하는 방법을 안내합니다.

## 1. 기기 안에 저장된 데이터

앱 안에서 직접 지울 수 있습니다.

| 방법 | 지워지는 것 |
|---|---|
| 앱 실행 → **설정 → 기록 초기화** | 테마·난이도별 최고 기록 |
| 순위표에서 가린 닉네임 목록 | 앱 데이터 삭제로 함께 지워집니다(기기 안에만 저장되며 서버로 전송되지 않습니다) |
| 앱 삭제, 또는 기기 설정 → 애플리케이션 → 메모리 게임 → 저장공간 → **데이터 삭제** | 기기에 저장된 **모든 데이터**(최고 기록·닉네임·통계·일일 도전 기록·효과음/진동 설정) |

즉시 삭제되며 별도 요청이 필요 없습니다.

## 2. 서버(랭킹)에 저장된 데이터

글로벌 랭킹에 기록을 올린 적이 있다면 아래 정보가 서버(Google Firebase Realtime Database, 아시아 남동부 리전)에 저장되어 있습니다.

- 닉네임 (공개 리더보드에 표시)
- 익명 식별자(uid) — 앱이 자동 생성한 무작위 문자열
- 게임 기록 — 소요 시간(초), 뒤집기 횟수, 갱신 시각

다른 이용자의 닉네임을 신고한 적이 있다면 신고 기록도 함께 저장되어 있습니다.

- 신고자·신고 대상의 익명 식별자(uid), 신고 대상 닉네임, 신고 사유, 신고 시각

**삭제 방법**: 아래 이메일로 요청해 주세요.

> **firepig.jjanggu@gmail.com**
> 제목 예시: `[메모리 게임] 랭킹 데이터 삭제 요청`
> 본문에 **리더보드에 표시되는 닉네임**을 적어 주세요. 해당 기록을 찾아 삭제합니다.

- 처리 기간: 요청 접수 후 **7일 이내**
- ⚠ 앱을 삭제하는 것만으로는 서버의 랭킹 기록이 지워지지 않습니다. 위 이메일 요청이 필요합니다.

## 3. 보관 기간

- 기기 내 데이터: 이용자가 지울 때까지
- 서버 랭킹 기록: 무기한 보관하며, 삭제 요청 시 삭제합니다.

본 앱은 회원가입·로그인이 없습니다. 이름·이메일·전화번호 등 이용자를 특정할 수 있는 정보는 수집하지 않으며, 삭제할 계정 자체가 존재하지 않습니다.
