# 개인정보처리방침 (memory_match)

**시행일: 2026-08-18** (앱 최초 출시일) · **최종 수정: 2026-08-22** (신고 기능 관련 항목 추가)

## 1. 수집하는 정보

### 1.0 익명 식별자 (앱 실행 시 자동 생성)
앱을 처음 실행하면 Firebase 익명 인증으로 무작위 식별자(uid)가 자동 생성됩니다. 이 값은 랭킹 이용 여부와 관계없이 생성되며, 이름·이메일·전화번호 등 이용자를 특정할 수 있는 정보와 연결되지 않습니다. 랭킹에 기록을 올릴 때 본인 기록을 식별하는 용도로만 쓰입니다.

### 1.1 글로벌 랭킹 기능 (선택적)
사용자가 게임 기록을 랭킹에 등록할 때 다음 정보를 수집합니다.

- **닉네임**: 사용자가 설정 화면에서 직접 입력한 별칭(공개 리더보드에 표시)
- **Firebase 익명 인증 식별자(uid)**: 중복 제출 방지 및 본인 기록 관리 목적의 기술적 식별자. 리더보드를 조회할 때 다른 이용자의 기기로도 함께 전달되나, 무작위 문자열이며 화면에는 표시되지 않습니다.
- **게임 기록**: 최고 시간(초), 그때의 뒤집기 수, 갱신 시각(ms)

**수집 목적**: 글로벌 랭킹 시스템 운영 (상위 50개 기록 표시)

**보관 위치**: Google Firebase Realtime Database(RTDB, 아시아 남동부 리전)

**보관 기간**: 무기한(사용자 요청 시 삭제 가능 — 문의 안내 참조)

### 1.2 부적절한 닉네임 신고 (선택적)
리더보드에서 다른 이용자의 닉네임을 신고하면 다음 정보가 서버에 기록됩니다. 신고 내용은 운영자만 확인하며, 앱에서 다시 조회할 수 없습니다.

- **신고자의 익명 식별자(uid)**: 중복·허위 신고 확인 목적
- **신고 대상의 익명 식별자(uid)와 닉네임**: 조치 대상 확인 목적
- **신고 사유(선택한 항목)와 신고 시각**

**수집 목적**: 공개 리더보드에 부적절한 닉네임이 노출되지 않도록 하는 운영·조치

**보관 위치**: Google Firebase Realtime Database(아시아 남동부 리전)

**보관 기간**: 조치 완료 후 1년(허위·반복 신고 확인 목적), 이후 삭제

### 1.3 로컬 저장(기기 내)
회원가입·로그인이 없으며, 게임 기록·선호도 등 로컬 데이터는 기기 내부에만 저장되며 외부 서버로 전송되지 않습니다.

- 게임별 최고 기록(시간·뒤집기 수)
- 효과음·햅틱 설정
- 통계(플레이 횟수·평균 시간)
- 일일 도전 완료 기록
- 힌트 잔량과 마지막 충전 날짜
- 로컬 저장 닉네임 복사본
- 내가 순위표에서 가린 이용자의 익명 식별자 목록(내 기기에만 저장되며 전송되지 않습니다)

## 2. 외부 서비스 이용
본 앱은 기기에 내장된 기본 글꼴만 사용하며, 광고·분석 목적의 외부 서비스를 이용하지 않습니다. 외부와 통신하는 것은 §1의 랭킹 기능(Google Firebase)과 앱 최신 버전 확인(Google Play) 뿐입니다.

## 3. 권한
앱이 요청하는 권한은 해당 기능 제공 목적으로만 사용됩니다.

## 4. 제3자 제공
랭킹 기능 데이터(닉네임, uid, 게임 기록)와 신고 기록은 Google Firebase 서비스를 통해 Google에 제공되며, 글로벌 랭킹 시스템 운영과 부적절한 닉네임 조치에만 사용됩니다. 기타 개인정보는 제3자에게 제공되지 않습니다.

## 4-1. 이용자 보호 조치 (공개되는 닉네임에 대하여)
닉네임은 전 세계 이용자에게 공개되므로 다음 장치를 두고 있습니다.

- **사전 차단**: 욕설·선정적 표현·전화번호 형태의 긴 숫자가 들어간 닉네임은 저장 단계에서 거부됩니다.
- **신고**: 순위표의 각 기록 옆 깃발 버튼으로 부적절한 닉네임을 신고할 수 있습니다(§1.2).
- **가리기**: 신고하면 해당 닉네임은 신고하신 분의 순위표에서 즉시 보이지 않게 됩니다. 이 설정은 기기 안에만 저장됩니다.
- **조치**: 접수된 신고는 운영자가 확인해 해당 기록을 삭제할 수 있습니다.

## 5. 데이터 삭제

### 5.1 로컬 데이터(기기 내)
앱을 삭제하거나 기기 설정에서 앱 데이터를 삭제하면 저장된 모든 데이터가 즉시 삭제됩니다. 앱 안의 「설정 → 기록 초기화」는 최고 기록만 지우며, 닉네임·통계·일일 도전 기록과 아래 5.2의 서버 데이터는 지우지 않습니다.

### 5.2 랭킹 데이터·신고 기록(Firebase)
서버에 저장된 랭킹 기록(닉네임·익명 식별자·기록)과 내가 제출한 신고 기록은 아래 연락처로 요청해 주시면 확인 후 삭제해 드립니다. 앱 삭제만으로는 서버 기록이 지워지지 않습니다.

## 6. 아동의 개인정보
본 앱은 만 13세 이상을 대상으로 합니다. 아동을 표적으로 별도의 정보를 추가 수집하지는 않으나, 랭킹에 참여하면 연령과 무관하게 §1의 정보(닉네임·익명 식별자·게임 기록)가 수집되고 닉네임은 공개 리더보드에 표시됩니다. 보호자께서는 아동이 실명 등 개인을 특정할 수 있는 닉네임을 입력하지 않도록 지도해 주시고, 삭제를 원하시면 §8 연락처로 요청해 주세요.
