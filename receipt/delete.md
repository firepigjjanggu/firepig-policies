## 1. 이 앱이 보관하는 데이터

이 앱은 **회원가입·로그인이 없으며 서버를 운영하지 않습니다.**
따라서 개발자가 보관하는 이용자 데이터가 **없습니다.**

이용자가 앱에 등록한 아래 정보는 **이용자 기기 내부에만** 저장됩니다.

| 데이터 | 보관 위치 | 보관 기간 |
|---|---|---|
| 영수증 사진 | 기기 내부(앱 전용 폴더) | 이용자가 삭제할 때까지 |
| 상호·금액·부가세·거래일자·사업자등록번호·메모 | 기기 내부(앱 전용 폴더) | 이용자가 삭제할 때까지 |
| 카테고리 선택값 | 기기 내부(앱 전용 폴더) | 이용자가 삭제할 때까지 |

- 위 정보는 어떤 서버로도 전송되지 않습니다.
- 글자 인식(OCR)은 기기 안에서 처리되며 사진이 외부로 나가지 않습니다.
- 기기의 자동 클라우드 백업 대상에서도 제외되어 있습니다.

## 2. 데이터를 삭제하는 방법

### 방법 1 — 앱 안에서 개별 삭제 (권장)

1. 앱을 실행합니다.
2. 목록에서 삭제할 영수증을 **길게 누르거나**, 영수증을 눌러 상세 화면으로 들어갑니다.
3. 삭제를 선택하고 확인합니다.
4. 해당 영수증의 기록과 **함께 보관되던 사진 파일이 즉시 삭제**됩니다.

> 삭제 직후 잠시 동안 "되돌리기"가 표시되며, 그 시간이 지나면 완전히 삭제됩니다.

### 방법 2 — 전체 삭제

- **앱 삭제(제거)**: 기기에서 앱을 삭제하면 저장된 모든 영수증 기록과 사진이 함께 삭제됩니다.
- **앱 데이터 삭제**: 기기 설정 → 애플리케이션 → 영수증 스캐너 → 저장공간 → "데이터 삭제"를
  선택하면 앱을 지우지 않고도 모든 데이터가 즉시 삭제됩니다.

### 방법 3 — 이메일 요청

개발자가 보관하는 데이터가 없어 원격으로 삭제할 대상이 없습니다.
다만 문의가 필요하시면 **firepig.jjanggu@gmail.com** 으로 연락 주시면 안내해 드립니다.
(접수 후 7일 이내 회신)

필요하시면 삭제 전에 앱의 **설정 → 전체 백업 파일 만들기**로 백업해 두시기 바랍니다.
