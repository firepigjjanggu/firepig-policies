# 개인정보처리방침 (거래량 브리핑)

**시행일: 2026-08-09**

"거래량 브리핑"(패키지명 `com.firepigjjanggu.volume_briefing`, 이하 "본 앱")은 매일 아침 코스피·코스닥·미국 시장의 거래량 급증 종목을 정리한 브리핑을 보여주는 안드로이드 앱입니다. 본 방침은 본 앱이 이용자의 정보를 어떻게 다루는지 안내합니다.

## 1. 수집하는 정보

**본 앱은 개인정보를 일절 수집하지 않습니다.** 회원가입·로그인·서버 계정이 없고, 분석(Analytics)·충돌 보고(Crashlytics 등)·광고 SDK가 포함되어 있지 않습니다.

| 항목 | 수집 여부 |
|---|---|
| 이름·이메일·전화번호 등 식별정보 | 수집하지 않음 |
| 위치정보 | 수집하지 않음 |
| 기기 식별자·광고 ID | 수집하지 않음 |
| 사용 통계·분석 데이터 | 수집하지 않음 |
| 결제·금융 정보 | 수집하지 않음(본 앱은 매매·결제 기능이 없습니다) |

## 2. 외부 통신에 관한 안내

본 앱이 발생시키는 유일한 네트워크 통신은 GitHub이 운영하는 공개 콘텐츠 전송망(`raw.githubusercontent.com`)에서 공개 시장 데이터 파일(`brief.json`)을 정해진 시각(또는 새로고침 시)에 내려받는 것입니다.

- 이 요청은 인증이 필요 없는 공개 URL에 대한 단순 조회(GET)이며, 이용자를 식별하는 값(이름·기기ID·계정 등)을 담아 보내지 않습니다.
- 앱이 이용자별로 다른 요청을 보내지 않으므로, 이 통신만으로는 이용자 개인을 특정할 수 없습니다.
- 본 앱은 이 조회 외에 어떤 서버로도 데이터를 전송하지 않습니다.

## 3. 기기 내 저장(로컬 캐시·기록)

내려받은 브리핑 데이터와 과거 조회 기록(최근 30일)은 이용자의 기기 안에만 저장됩니다. 이는 인터넷 연결이 없을 때도 마지막 브리핑을 보여주기 위한 것으로, 서버로 전송되지 않으며 본 앱을 삭제하면 함께 삭제됩니다.

## 4. 접근 권한(permission) 안내

본 앱이 요청하는 권한은 아래 6종이며, 각각의 목적은 다음과 같습니다.

| 권한 | 목적 |
|---|---|
| `INTERNET` | 공개 브리핑 데이터(`brief.json`)를 GitHub 공개 저장소에서 내려받기 위해 필요합니다(§2 참조). 광고·추적 목적이 아닙니다. |
| `POST_NOTIFICATIONS` | 매일 아침 지정한 시각에 브리핑 알림을 보여주기 위해 필요합니다(Android 13 이상에서 필수 동의 권한). 허용하지 않으면 알림 대신 앱을 직접 열어야 브리핑을 볼 수 있습니다. |
| `SCHEDULE_EXACT_ALARM` | 지정한 시각에 정확히 알림을 울리기 위해 필요합니다. 이 권한을 허용하지 않아도 앱은 동작하며, 이 경우 알림이 정확한 시각보다 다소 늦게(비정시 방식으로) 울릴 수 있습니다. |
| `RECEIVE_BOOT_COMPLETED` | 기기를 재부팅해도 예약된 알림이 사라지지 않도록, 부팅 직후 알림 예약을 자동으로 다시 등록하기 위해 필요합니다. |
| `WAKE_LOCK` | 예약된 시각에 화면이 꺼져 있어도 브리핑 데이터를 내려받아 알림을 준비하는 짧은 시간 동안 기기가 절전 상태로 들어가지 않도록 하기 위해 필요합니다. |
| `VIBRATE` | 브리핑 알림이 도착했을 때 기기를 짧게 진동시키기 위해 필요합니다(알림 표시 라이브러리가 사용). 진동을 원하지 않으시면 안드로이드 설정 → 앱 → 알림에서 해당 알림 채널의 진동을 끄시면 됩니다. |

## 5. 제3자 제공

이용자의 개인정보를 수집하지 않으므로 제3자에게 제공·판매·공유하는 이용자 정보가 없습니다. GitHub의 공개 콘텐츠 전송망은 공개 시장 데이터를 배포하는 인프라일 뿐이며, 본 앱이 이용자 데이터를 그곳으로 전송하지 않습니다.

## 6. 보유 기간 및 파기

수집하는 개인정보가 없으므로 보유·파기 대상이 되는 개인정보가 존재하지 않습니다. 기기 내에 저장된 브리핑 캐시·조회 기록은 본 앱을 삭제하면 기기에서 함께 제거됩니다.

## 7. 이용자 권리

수집된 개인정보가 없어 열람·정정·삭제를 요청할 대상 정보가 없습니다. 기기 내 로컬 데이터를 직접 지우고 싶다면 본 앱을 삭제하면 즉시 제거됩니다.

## 8. 투자 관련 안내(면책)

본 앱이 제공하는 브리핑은 공개된 시장 데이터(거래량·등락 등)를 기계적으로 집계·요약한 것이며, **투자 자문·매매 추천·수익 보장이 아닙니다.** 데이터의 정확성·완전성·최신성은 원본 제공처의 사정에 따라 달라질 수 있으며, 본 앱과 개발자는 이를 근거로 이루어진 투자 판단이나 그로 인한 손실에 대해 책임을 지지 않습니다. 모든 투자 판단과 책임은 이용자 본인에게 있습니다.

## 9. 아동의 개인정보

본 앱은 어떤 이용자로부터도 개인정보를 수집하지 않으므로 아동의 개인정보 또한 수집하지 않습니다. 다만 만 14세 미만 아동은 보호자의 지도 아래 이용할 것을 권장합니다.
