# 개인정보처리방침 (스도쿠 배틀)

**시행일: 2026-05-27**

본 개인정보처리방침은 "스도쿠 배틀" 모바일 앱(이하 "본 앱")의 개인정보 처리 기준을 안내합니다.

## 1. 수집하는 정보

본 앱은 최소한의 정보만 수집합니다:

| 항목 | 내용 | 목적 |
|------|------|------|
| 익명 ID (UID) | Firebase Authentication이 자동 생성한 무작위 식별자 | 사용자 식별 (실명/계정 정보 아님) |
| 닉네임 | 사용자가 직접 입력 (실명 금지) | 친구와 대결 시 상대에게 표시, 단계별 랭킹 표시 |
| 게임 기록 | 클리어 시간, 단계별 최고 기록, 포인트, 승률, 힌트 사용 수 | 본인 통계, 단계별 랭킹 |
| 기기 정보 | OS 버전, 앱 버전, 충돌 로그 (Firebase Crashlytics) | 앱 안정성 개선 |
| IP 주소 | Firebase 서버 접속 시 자동 기록 | 보안, 부정 사용 방지 |

**수집하지 않는 정보**: 실명, 이메일, 전화번호, 주소, 학교명, 광고 ID 등 개인 식별 정보를 일체 수집하지 않습니다.

**광고 없음**: 본 앱은 광고를 표시하지 않으며 광고 ID(GAID)도 사용하지 않습니다.

## 2. 만 14세 미만 아동의 개인정보

본 앱은 유아·초등학생을 포함한 4세 이상 모든 연령이 사용 가능하나, **만 14세 미만 아동의 경우 법정대리인(부모/보호자)의 동의를 얻은 후 사용**하셔야 합니다 (개인정보보호법 제22조의2).

- 본 앱은 익명 ID만 사용하며 실명 등 직접적인 개인정보를 수집하지 않습니다.
- 닉네임은 본인 또는 보호자가 임의로 정한 별칭을 사용합니다.
- 유아 단계(4×4)는 부모와 함께 사용을 권장합니다.
