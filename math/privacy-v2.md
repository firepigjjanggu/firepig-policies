# 개인정보처리방침 (수학 대결)

**시행일: 2026-11-06** · **최종 개정일: 2026-10-30** · **적용 앱 버전: 1.1.0 이상**

본 개인정보처리방침은 "수학 대결" 모바일 앱(이하 "본 앱")의 개인정보 처리 기준을 안내합니다. 본 앱은 초등학생이 주로 이용하므로, 어린이와 보호자께서 쉽게 읽으실 수 있도록 작성하였습니다.

## 2. 만 14세 미만 아동의 개인정보

본 앱은 초등학생을 포함한 모든 연령이 사용 가능하나, **만 14세 미만 아동의 경우 법정대리인(부모/보호자)의 동의를 얻은 후 사용하셔야 합니다** (개인정보보호법 제22조의2).

- 본 앱은 익명 ID만 사용하며 실명 등 직접적인 개인정보를 수집하지 않습니다.
- 닉네임은 본인 또는 보호자가 임의로 정한 별칭을 사용합니다.
- 법정대리인 동의는 앱 최초 실행 시(기존 이용자는 1.1.0 첫 실행 시 재동의 화면에서) 화면의 확인 항목으로 확인합니다. 별도의 법정대리인 본인 확인 절차는 두지 않습니다.
- 다른 이용자의 부적절한 닉네임을 발견하면 신고 기능으로 알릴 수 있으며, 신고된 내용은 아동 보호를 위한 검토에만 사용됩니다.
- **아동 대상 광고 처리**: 본 앱은 광고 요청 시 "아동 대상 서비스" 및 "미성년자 동의 연령 미만" 설정을 적용하고, 콘텐츠 등급을 전체 이용가(G) 수준으로 제한합니다. **맞춤형(관심 기반) 광고와 광고 ID는 사용하지 않습니다.** 광고는 홈·결과 화면 등 일부 화면의 하단 배너 1개로만 표시되며, 퀴즈·대결 진행 중, 대기실, 동의, 설정 화면에는 표시되지 않습니다.

## 제4조의4. 광고 제거 코드 확인

- 설정 화면에서 광고 제거 코드를 입력하면, 입력한 값은 **확인을 위해 서버(Firebase 데이터베이스)의 코드 목록과 대조하는 데에만** 사용됩니다. 입력값은 서버에 저장·기록하지 않고 앱 기기에도 저장하지 않습니다.
- 확인 결과(성공 여부)만 기기에 저장되며, 성공한 기기에서는 광고가 표시되지 않습니다.
- 서버 대조 시 익명 ID와 IP 주소가 제1조의 범위 내에서 Firebase 접속 정보로 처리될 수 있습니다.
