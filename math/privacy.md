# 개인정보처리방침 (수학 대결)

**시행일: 2026-05-23** · **최종 개정일: 2026-07-28**

본 개인정보처리방침은 "수학 대결" 모바일 앱(이하 "본 앱")의 개인정보 처리 기준을 안내합니다.

## 1. 수집하는 정보

본 앱은 최소한의 정보만 수집합니다:

| 항목 | 내용 | 목적 |
|------|------|------|
| 익명 ID (UID) | Firebase Authentication이 자동 생성한 무작위 식별자 | 사용자 식별 (실명/계정 정보 아님) |
| 닉네임 | 사용자가 직접 입력 (실명 금지) | 대결 상대 및 랭킹 화면에서 다른 모든 이용자에게 공개 |
| 게임 기록 | 점수, 정답/오답 | 본인 학습 통계, 대결 결과 표시, 학년별 랭킹 공개(닉네임·점수) |
| 기기 정보 | OS 버전, 앱 버전, 충돌 로그 (Firebase Crashlytics) | 앱 안정성 개선 |
| 사용 통계 | 화면 진입, 게임 모드 사용량 (Firebase Analytics) | 서비스 개선 |
| IP 주소 | Firebase 서버 접속 시 자동 기록 | 보안, 부정 사용 방지 |
| 광고 식별자(AAID) | Google Play 서비스가 기기에 부여한 재설정 가능한 광고 ID (Google AdMob SDK가 접근) | 광고 게재 및 성과 측정, 노출 빈도 제한 |
| 앱·기기 무결성 신호 | Google Play Integrity API(Firebase App Check)가 확인하는 앱 위·변조 여부 및 기기 무결성 판정값 | 부정 사용·랭킹 조작 방지 |

**수집하지 않는 정보**: 실명, 이메일, 전화번호, 주소, 학교명 등 개인 식별 정보를 일체 수집하지 않습니다. 다만 위 표에 기재한 광고 식별자(AAID)는 광고 SDK를 통해 수집·이용되며, 기기 설정에서 언제든지 재설정하거나 맞춤 광고를 해제할 수 있습니다. 앱·기기 무결성 신호 역시 개인을 식별하지 않는 기술적 판정값이며, 이용자를 특정하는 데 사용되지 않습니다.

## 2. 만 14세 미만 아동의 개인정보

본 앱은 초등학생을 포함한 모든 연령이 사용 가능하나, **만 14세 미만 아동의 경우 법정대리인(부모/보호자)의 동의를 얻은 후 사용하셔야 합니다** (개인정보보호법 제22조의2).

- 본 앱은 익명 ID만 사용하며 실명 등 직접적인 개인정보를 수집하지 않습니다.
- 닉네임은 본인 또는 보호자가 임의로 정한 별칭을 사용합니다.
- 법정대리인 동의는 앱 최초 실행 시 화면에서 확인합니다.
- 본 앱은 모든 광고 요청을 '아동 대상(child-directed)' 및 '동의 연령 미만'으로 설정하여 **맞춤형(관심 기반) 광고를 적용하지 않으며**, 광고 콘텐츠 등급을 전체 이용가(G)로 제한합니다.

## 3. 보유 및 이용 기간

| 항목 | 기간 |
|------|------|
| 대결방(rooms — 닉네임, 점수, 출제 문항) | 방을 나가거나 대결을 마치고 홈으로 돌아오면 즉시 삭제 (아래 ※ 참고) |
| 닉네임, 통계 | 이메일 삭제 요청 처리 시까지 보관 (요청 접수 후 14일 이내 삭제) |
| 랭킹 기록(rankings/solo — 닉네임, 최고 점수) | 이메일 삭제 요청 처리 시까지 보관 (자동 삭제 없음, 학년별 랭킹에 공개) |
| Crashlytics 충돌 로그 | 최대 90일 |
| Analytics 통계 | 최대 14개월 (Firebase 기본값) |

※ **대결방 삭제 방식 안내**: 대결방 정보(닉네임, 점수, 출제 문항)는 이용자가 방에서 나가거나 대결을 마치고 홈으로 돌아오는 시점에 삭제됩니다. 또한 **아직 아무도 참가하지 않은 대기 상태의 방**은, 방을 만든 이용자의 앱이 종료되거나 통신이 끊기면 서버가 자동으로 삭제합니다. 다만 **도전자가 참가한 뒤, 또는 대결이 진행 중이거나 결과 화면인 상태에서 앱이 비정상 종료되면 해당 대결방 정보가 서버에 남을 수 있으며, 일정 기간이 지난 방을 일괄 삭제하는 서버 기능은 현재 제공하지 않습니다.** 이렇게 남은 대결방 정보는 제6항의 삭제 요청으로 삭제해 드리며, 남는 정보에는 실명 등 개인 식별 정보가 포함되지 않습니다.
