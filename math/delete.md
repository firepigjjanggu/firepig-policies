# 데이터 삭제 요청 안내 (수학 대결)

- **앱 이름:** 수학 대결 (math_battle_app)
- **개발자:** firepig
- **문의:** firepig.jjanggu@gmail.com

본 페이지는 「수학 대결」 앱 이용자가 자신의 데이터 삭제를 요청하는 방법을 안내합니다.

## 1. 기기에만 저장되는 데이터 (앱 삭제로 자동 제거)

오답노트, 효과음·진동 설정 등은 이용자의 기기 안에만 저장됩니다. 앱을 삭제하거나 기기 설정에서 앱 데이터를 지우면 별도 요청 없이 즉시 함께 삭제됩니다.

## 2. 이메일로 삭제 요청

닉네임, 랭킹 기록 등 서버(Firebase)에 저장된 데이터는 앱 내 삭제 기능이 제공되지 않으므로, 아래 이메일로 요청해 주시면 처리해 드립니다.

- **이메일:** firepig.jjanggu@gmail.com
- **제목 예시:** `[데이터 삭제 요청] 수학 대결`
- 요청 시 앱 내에 표시된 **닉네임**을 함께 알려주시면 대상 확인에 도움이 됩니다.
- 요청 접수 후 **14일 이내** 처리하고 결과를 회신합니다.

## 3. 삭제되는 데이터 항목

| 데이터 | 처리 |
|---|---|
| 닉네임 | 삭제 요청 처리 시 **삭제** |
| 게임 기록(점수, 정답/오답 통계) | 삭제 요청 처리 시 **삭제** |
| 랭킹 기록(학년별 랭킹에 공개된 닉네임·최고 점수) | 삭제 요청 처리 시 **삭제** (자동 삭제 없음) |
| 대결방 정보(닉네임, 점수, 출제 문항) | 대결 종료·방 나가기 시 **자동 즉시 삭제**. 앱 비정상 종료로 남은 경우 삭제 요청 시 삭제 |
| 익명 인증 ID(UID) | 삭제 요청 처리 시 **삭제** |
| Crashlytics 충돌 로그 | **최대 90일** 후 자동 삭제 |
| Analytics 사용 통계 | **최대 14개월**(Firebase 기본값) 후 자동 삭제 |
| 신고 기록(신고 사유, 신고자·신고 대상 익명 ID, 신고 시각) | 아동 보호 검토 목적으로 보관 — 이용자 열람·삭제 요청 대상에서 제외 |

## 4. 유의 사항

본 앱은 실명, 이메일, 전화번호 등 개인 식별 정보를 수집하지 않으므로, 삭제 요청 시 계정 정보 대신 닉네임 등 앱 내 식별자로 대상을 확인합니다. 확인이 어려운 경우 추가 정보를 요청드릴 수 있습니다.
